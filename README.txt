VOLLEYBALL TEAM BUILDER - VERSION 1.2

Upload all files in this ZIP to the root of the existing static host. Keep index.html at the root.

IMPORTANT UPDATE STEPS
1. Export a roster backup before updating.
2. Replace the existing hosted files with these Version 1.2 files.
3. Open the hosted site in a private Safari window first to verify Version 1.2.
4. Then reopen the normal Safari/Home Screen app while online. The service worker uses a new cache name and network-first navigation.
5. If an older build remains, remove only that site's Safari website data, reopen online, then add it to the Home Screen again. Import the backup if needed.

Version 1.2 retains the existing IndexedDB database name, so an in-place update on the same website origin migrates old players automatically. Existing players receive blank designation and no tags.

This static release stores data separately on each device. Export/import is the supported way to share roster and session history with a co-organizer.
