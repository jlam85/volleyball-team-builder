VOLLEYBALL TEAM BUILDER - CHANGELOG
===================================

Version 1.5.1 - August 12, 2026
-------------------------------
- Added visible X and Cancel controls to Add Player and Edit Player screens.
- Added confirmation before discarding unsaved player changes.
- Added defensive local-state migration and empty-roster overwrite protection.
- Added a localStorage shadow copy while retaining the existing IndexedDB database, object store, and record key.
- Added local roster load status messages.
- Renamed Filters to Sort / Filter and added name, rating, and recently-added sort options.

- Expanded rating filters through 10.0.
- Export filenames now use volleyball-roster-v1.5.1-YYYYMMDDTHHMMSS.json.
- Preserved Version 1.5 tap-to-move, pooled reshuffle, no-history behavior, import timestamps, optimizer, passcode, and publishing behavior.

VOLLEYBALL TEAM BUILDER - CHANGELOG
===================================

Version 1.5 - August 5, 2026
----------------------------
- Added tap-to-move player workflow with a persistent destination-team tray for mobile.
- Retained desktop drag as an optional shortcut.
- Rebuilt reshuffle to pool all players from unlocked teams and redistribute them across the existing unlocked team slots, regardless of temporary roster sizes.
- Removed published-session history storage, history settings, and all history penalties from matching.
- Publish now validates and displays final teams without retaining the result.
- Added imported-roster filename, file-modified timestamp, and actual import timestamp.
- Added compact roster date under the app version and detailed import metadata on the Players tab.
- Roster metadata updates only after successful import and marks local player edits.
- Redesigned Players tab to show roster first with Filters and Add New actions.
- Added multi-select filters for name, rating bands, designation, tags, tag match mode, assessment completeness, and current-session selection.
- Preserved Version 1.4 rating, tag, Coed, locking, publishing, passcode, storage, and iOS action-bar behavior.

VOLLEYBALL TEAM BUILDER - CHANGELOG
===================================

Version 1.4 - July 29, 2026
---------------------------
- Changed drag-and-drop from swap behavior to move-only behavior.
- Dropping over any part of an unlocked destination team moves the dragged player into that team.
- Unlocked teams may temporarily contain any number of players, including zero.
- Empty teams remain visible and show a Drop players here target.
- Team average, Coed status, core-player count, and Tags update after every move.
- Finalized teams may contain 2-5 players.
- Lock and Publish reject teams with fewer than 2 or more than 5 players.
- Reshuffle rejects unlocked teams outside 2-5 players.
- Initial generation now supports 2-player teams while retaining an even team count and selected-court limit.
- Added visual-viewport synchronization for the Teams action bar so Reshuffle and Publish remain anchored to the bottom of the visible iOS screen.
- Preserved Version 1.3.1 passcode compatibility, IndexedDB storage, ratings, tags, history, backup/import, and publishing privacy.
